## 已完成

1. **舊任務圖片隔離。** 暫存圖片依結果分頁與任務 ID 確認擁有者，
   commit／replaceResult 在任務仍有效且儲存成功後才更新圖片。
   hydration 與 publish 不再暗中修改圖片快取。
   同話部分重翻及合法 resume 可繼承已完成圖片，換話會隔離舊圖片。
2. **原子合併重譯。** job store 支援同步 updater，在既有儲存佇列中
   對最新頁面做單行更新。不同兩行可並行合併，不會還原另一行。
   已被其他操作修改的目標行／整頁、已換掉的任務會拒絕晚到結果，
   向使用者回應「頁面或任務已更新，請重新發起重譯」。
   文字重譯也檢查回應行數，避免不完整輸出截掉已保存內容。
3. **整本缺頁檢查。** 搜集圖片時保存缺頁頁碼，有任一頁尚未取得即停止派發，
   告知缺頁並恢復按鈕讓使用者重試。所有頁面取得後按原次序送出。
4. **補回台灣用語。** 保留易混字的詞彙保護；簡繁字形正規化後，
   再套用以相同字元表正規化的詞彙鍵，支援繁體及簡繁混合輸入。
   補回使用者、複製、音訊、硬碟、光碟、選單、二進位、啟用及儲值等原有用語。
