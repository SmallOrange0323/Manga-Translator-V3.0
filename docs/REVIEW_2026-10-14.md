## 1. [P1] 舊任務會污染新任務的暫存圖片

位置：`src/background/manga-recovery.js:112-113`，相同問題在 `134-137`。

`commit` 和 `replaceResult` 先更新按 resultTabId/pageIndex 索引的記憶體圖片，
才交給 job store 檢查 job.id 或 canCommit。舊任務或遲到的重譯回應被拒絕時，
回傳值雖為 null，記憶體 Map 已經被覆蓋。新任務的 data:image 不持久化在結果列，
後續 snapshot 會從這個 Map 補圖，造成新譯文配到舊任務圖片。

重現：同一結果分頁建立 A、再建立 B，B 第一頁是暫存圖 NEW，成功提交 B 後，
讓 A 的舊 commit 帶著同頁碼圖片 OLD 到達。

- 舊 commit 回傳 null，B 的 job.id 及譯文均維持正確。
- B 的 snapshot 圖片卻變成 `data:image/jpeg;base64,OLD`。
- 舊 A 的 replaceResult 同樣回傳 null，但仍把 B 圖片改成 STALE_RETRANSLATE。

建議：圖片快取以任務身分及頁碼隔離；只有接受成功的 commit／replaceResult
才能更新快取。處理非同步間隔期間任務被取代的情況，不能只在 await 前檢查 id。
補上「換任務後舊 commit／重譯回應」、「STOP 拒絕提交」與「原分頁消失」測試。

## 2. [P1] 同頁多行重譯會互相覆寫已完成的譯文

位置：`src/background/index.js:1722-1736`。

每次單行重譯在發起 API 前取得 initialJob，API 完成後用這份舊快照的整個
existingRow.results 合併單行並覆寫全頁。兩行同時翻譯時，即使 job.id 未改變，
第二個完成的請求仍會把第一行的新譯文還原。job store 的寫入序列化不能保護
早先快照建構的整頁資料。

重現：原頁兩行是 OLD_A、OLD_B，兩個請求同時取得相同快照；第一個回傳 NEW_A，
第二個回傳 NEW_B。兩個呼叫均回應成功，最終保存卻是 `[OLD_A, NEW_B]`。

建議：在 job store 的序列化更新內，按 pageIndex/lineIndex 修改目前最新那一行，
不要用 API 前的整頁快照覆寫。另需考慮同一行重複請求和整頁重譯的晚到結果，
可用行或頁的 revision/token 決定所有權。補不同兩行並行、反序完成及全頁／單行競爭測試。

## 3. [P2] 串流整本翻譯會靜默跳過無法解析的頁面

位置：`src/reader/stream-reader.js:659-670`。

新增 resolvePageDirectImageUrl 失敗時回傳 null，但 translateAllPages 只把成功的
圖片 push 到新陣列，僅在整本一張也沒有時顯示錯誤。因此單頁暫時 HTTP 失敗或
解析失敗會直接從翻譯任務消失，後面頁面的頁碼也因陣列壓縮而前移。

重現：模擬三頁，其中第二頁 FETCH_HTML 回傳 `{success:false,error:'HTTP 503'}`。
START_MANGA_BATCH_PC_MODE 仍收到 `[page-1/image.jpg, page-3/image.jpg]`，
沒有缺頁提示；新結果頁第二頁實際是原第三頁。

建議：發送前檢查成功頁數與 totalPages 相符；有缺頁時停止並顯示頁碼／重試。
若允許部分翻譯，必須保留原始頁碼及缺頁卡片，不能壓縮成連續頁碼假裝整本完成。
補三頁中間一頁失敗、第一頁失敗及全部失敗測試。

## 4. [P2] 新在地化模組退步，漏掉繁體形式與既有用語

位置：`src/utils/zh-tw-localizer.js:196-208`，套用流程在 `470-478`。

目前詞彙主要只列簡體寫法，且先做詞彙替換再做字元轉換。已是繁體的模型譯文
不會命中「视频／网络／默认」，而「用户／复制」等舊詞也未保留。
在預設要求 zh-TW 的輸出中，這些繁體形式本來就是常見輸入，屬可重現的回歸。

實際對照 HEAD 與新版相同輸入：

| 輸入 | HEAD 舊版輸出 | V3.2.0 輸出 |
| --- | --- | --- |
| 視頻與網絡，默認用戶可以複制 | 影片與網路，預設使用者可以複製 | 視頻與網絡，默認用戶可以複制 |

另外「视频与网络，默认用户可以复制」新版輸出為
「影片與網路，預設用戶可以復制」，與舊版用語處理目標也不一致。

建議：將簡繁字形轉換與台灣用語替換分開，保留易混字保護；用語表需涵蓋簡體、
繁體及混合輸入，補回原來支援的詞。補繁體、簡體、混合輸入及已正確 zh-TW
文字不被誤改的回歸測試。
